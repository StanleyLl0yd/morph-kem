# Security Policy

## Important status

MORPH-KEM is experimental cryptographic research. It is **not intended for production use** and currently makes no claim of practical cryptographic security.

Do not use this repository to protect real secrets or communications.

## Reporting cryptanalytic findings

Cryptanalytic results are welcome, including:

- key or seed recovery;
- public-key structural recovery;
- distinguishers on generated instances;
- reductions in effective search complexity;
- malformed-ciphertext or oracle attacks;
- side-channel observations;
- correctness failures;
- parameter-generation bias;
- quantum or classical algorithmic improvements.

For findings that could matter to an unpublished research milestone, contact the repository owner privately through GitHub before public disclosure when practical. Otherwise, a GitHub issue is appropriate once the repository is public.

## What is not a vulnerability

Breaking MORPH-KEM is not considered misuse of the project. Successful cryptanalysis is a primary project objective and should be documented reproducibly.
