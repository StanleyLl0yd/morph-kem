# 10 — M1 non-local branching-path experiment

## Status

M1 is an executable attack experiment, not a KEM, not a trapdoor primitive, and not a security candidate.

Its purpose is to test one narrow hypothesis raised by M0:

> If selected bits no longer leave independent coordinate-local markers, is a public layered construction meaningfully harder to invert?

For the present M1 construction the answer is **no**. A generic meet-in-the-middle attack recovers path preimages in roughly square-root-of-exhaustive path enumeration.

## Construction

M1 starts from one shared finite 2-dimensional simplicial scaffold using a complete public vertex universe.

For each layer i the public instance contains two vertex permutations:

~~~text
P_i,0
P_i,1
~~~

Both are bijections on the same vertex universe. Generation enforces large support for each branch and for the relative permutation between the two branches.

For an ell-bit seed s, forward evaluation is:

~~~text
X_0 = public base

X_(i+1) = relabel(X_i, P_i,b_i)
b_i = (s >> i) & 1

C = X_ell
~~~

Each selected branch therefore acts globally on the current complex. There is no M0-style public candidate triangle whose direct presence reveals one selected bit.

## Deterministic generation

Instance generation is deterministic from:

- parameter-set name;
- layer count;
- vertex count;
- minimum permutation-support fraction;
- non-empty master seed.

Candidate permutations are generated by a domain-separated SHA-256 stream and Fisher-Yates shuffle. This is only a reproducibility mechanism for the experiment.

## Global-support condition

For a branch permutation P, define support as:

~~~text
support(P) = |{v : P(v) != v}|
~~~

M1 requires both branch permutations to meet the configured support threshold.

It also checks the relative transformation between the two choices at each layer, so two individually global branches cannot differ in only a tiny local region.

This removes the exact A-000 failure mode but does not imply cryptographic hardness.

## Exact relation

~~~text
PathAccept(instance, s, C) :=
    PathForward(instance, s) == C
~~~

All equality comparisons are on the canonical simplicial-complex representation inherited from M0.

## A-008 — generic meet-in-the-middle recovery

Let the path contain ell layers and split after k layers.

### Forward half

Enumerate all 2^k prefixes from the public base and store their middle states:

~~~text
prefix -> X_k
~~~

### Reverse half

Every public branch is a permutation, so its inverse is public and always maps a valid simplicial complex to another valid simplicial complex.

Starting from target C, enumerate all 2^(ell-k) suffix branch words backwards:

~~~text
C
 -> P_(ell-1,b)^-1
 -> ...
 -> P_(k,b)^-1
 -> candidate X_k
~~~

A matching middle state joins a prefix and suffix into a full candidate seed. The candidate is verified by ordinary public forward evaluation.

For balanced k:

~~~text
time/state enumeration: O(2^(ell/2))
memory:                 O(2^(ell/2))
~~~

up to the cost of state relabeling, canonical encoding, hash-table operations, and collision multiplicity.

## Why the attack is structurally important

The failure is not caused by a weak choice of permutation size.

The generic attack follows from three design properties:

1. the construction is a public layered path;
2. every step has only two public choices;
3. every public step is efficiently invertible.

Making each branch touch 75%, 95%, or 100% of vertices does not remove the attack.

Therefore **non-locality alone is insufficient**.

## Collision profiling

M1 includes exhaustive output-collision profiling for bounded experiment sizes.

For each seed in a selected small parameter set it records the canonical final state and reports:

- total seeds;
- unique outputs;
- number of outputs with multiplicity greater than one;
- maximum multiplicity.

The tested path-12 instance had:

~~~text
4096 seeds
4096 unique outputs
0 colliding outputs
maximum multiplicity 1
~~~

This is only one deterministic experiment instance. It is not a general injectivity result.

## What M1 establishes

M1 establishes a second negative design result:

- A-000 can be removed by making public effects non-local;
- high branch support does not by itself create inversion hardness;
- a public sequence of efficiently reversible low-branching transforms admits generic bidirectional search;
- a future construction must obtain asymmetry from something stronger than a hidden word in public invertible transformations.

## Consequence for M2

The next experiment should introduce a structural asymmetry that prevents trivial reverse enumeration.

Candidate directions include:

- non-invertible public reductions with many possible predecessors;
- expansion/reduction systems where the trapdoor selects a useful global reduction but reverse local choices branch explosively;
- overlapping Morse gadgets whose useful cancellation order is global rather than coordinate-local;
- hidden certificates that enable canonical reduction without exposing a publicly reversible layered path.

M2 should still be attacked before any KEM wrapper is introduced.
