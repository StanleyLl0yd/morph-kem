# 01 — Mathematical foundation

## Objects

The initial proposal uses finite simplicial complexes, with possible later generalization to regular CW complexes if that improves compactness or control over reductions.

A finite simplicial complex is denoted

[
X=(V,S),
]

where (V) is a finite vertex set and (S) is a downward-closed family of finite subsets of (V).

The dimension of a simplex (sigma) is (|sigma|-1). The dimension of (X) is the maximum simplex dimension in (S).

## Elementary reduction intuition

A free face can permit an elementary collapse. A sequence of valid collapses can reduce a complex while preserving homotopy type.

Discrete Morse theory represents useful collapse structure through matchings on the Hasse diagram. The research proposal relies on a secret acyclic matching that makes a chosen generated family easy to reduce.

## Trapdoor intuition

For an instance (X), let (M) denote a secret globally consistent reduction certificate.

Desired asymmetry:

[
operatorname{Reduce}(X,M)
]

is polynomial-time, while recovering an equivalent useful certificate (M') from public data alone is conjectured hard on the generated distribution.

This is only an intended asymmetry. Establishing it is a core research problem.

## Canonicalization requirement

Any cryptographic encoding of a complex must have an unambiguous canonical byte representation. Two semantically identical objects must not produce attacker-controlled parser ambiguities.

A future formal specification must define:

- vertex ordering;
- simplex ordering;
- integer encoding;
- duplicate rejection;
- dimension limits;
- canonical serialization;
- exact equality semantics.

## Distribution matters

The cryptographic object is not "all simplicial complexes." It is a distribution

[
mathcal D_lambda
]

generated by KeyGen at security parameter (lambda). All hardness claims must concern this distribution or a precisely related distribution, not merely a worst-case combinatorial problem.
