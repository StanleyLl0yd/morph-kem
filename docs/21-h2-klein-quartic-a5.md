# 21 — H2-H Klein quartic + A5 experiment

## Status

H2-H is an executable attack-first experiment using an exact finite hyperbolic surface.

It is not a KEM, one-way function, or security candidate.

The research question is:

> after replacing H1's graph surrogate by the genuine {3,7} Klein-quartic map and replacing S3 by perfect group A5, does the pairwise synchronization relation remain cheaply solvable?

## 1. Exact hyperbolic scaffold

The Klein quartic is a closed orientable hyperbolic surface of genus 3 with a regular {3,7} triangulation.

The implementation uses:

[
GL(3,2)cong PSL(2,7),
qquad |G|=168,
]

and deterministically finds generators:

[
r^2=s^3=t^7=rst=1.
]

Using left cosets of the corresponding cyclic subgroups:

- vertices are cosets of <t>, index 24;
- edges are cosets of <r>, index 84;
- faces are cosets of <s>, index 56.

Flag incidence is induced by common group elements.

The exact required invariants are:

[
V=24,quad E=84,quad F=56,
]

[
chi=V-E+F=-4,
]

and therefore:

[
g=rac{2-chi}{2}=3.
]

Every vertex has degree 7 and every edge belongs to two triangular faces.

## 2. Why this is genuinely hyperbolic

A Euclidean regular triangulation has six triangles around an interior vertex.

Here seven triangles meet at every vertex.

For a regular {p,q} tiling, hyperbolicity occurs when:

[
rac1p+rac1q<rac12.
]

For {3,7}:

[
rac13+rac17=rac{10}{21}<rac12.
]

Thus the combinatorics is the finite quotient of a true hyperbolic triangular tiling, not merely a graph drawn in a hyperbolic style.

## 3. Transition group A5

The local frame group is:

[
A_5,
qquad |A_5|=60.
]

The public accepted class is the conjugacy class of 3-cycles:

[
C_3subset A_5,
qquad |C_3|=20.
]

A5 is perfect:

[
[A_5,A_5]=A_5,
]

so its abelianization is trivial.

The implementation audits:
- group order = 60;
- 3-cycle class size = 20;
- class element order = 3;
- commutator subgroup size = 60;
- subgroup generated by all 3-cycles has size 60.

This explicitly removes the H1 failure:

[
S_3	o mathbb Z_2.
]

It does **not** imply the new relation is hard.

## 4. Public relation

Each Klein-quartic vertex v has a hidden frame:

[
x_vin A_5.
]

For canonical public edge u<v, generation chooses:

[
c_{uv}in C_3
]

and publishes:

[
T_{uv}=x_v^{-1}c_{uv}x_u.
]

A candidate frame assignment y is accepted iff:

[
y_vT_{uv}y_u^{-1}in C_3
]

on every edge.

The planted frames are reference data only.

Any accepted equivalent assignment is attacker success.

## 5. Global gauge

Because C3 is a conjugacy class, common left multiplication:

[
y_vmapsto gy_v
]

conjugates every normalized transition by g and preserves membership in C3.

The exact solver therefore fixes one public representative:

[
y_0=1.
]

This removes only the obvious global gauge orbit.

## 6. H-H01 exact CSP attack

Each of the remaining 23 vertices begins with a 60-element domain.

For edge u<v and fixed candidate y_u, the allowed y_v values are computed exactly from:

[
y_vT_{uv}y_u^{-1}=c,qquad cin C_3,
]

so:

[
y_v=c,y_u,T_{uv}^{-1}.
]

Therefore each fixed endpoint value has exactly 20 possible partner values before intersections with other constraints.

The solver uses:

1. exact compatibility tables;
2. repeated arc consistency;
3. minimum remaining values;
4. vertex degree as public tie-breaker;
5. exact backtracking;
6. bounded equivalent-solution enumeration.

No secret/reference data is used by the attack.

## 7. Hyperbolic symmetry warning

The Klein quartic is exceptionally symmetric. Its orientation-preserving automorphism group has order 168.

That is mathematically elegant but potentially dangerous cryptographically.

A symmetric scaffold may:
- make public coordinates highly canonical;
- create many equivalent witnesses;
- expose representation-theoretic attacks;
- help rather than hinder synchronization algorithms.

Hyperbolicity is not treated as hardness.

## 8. Exit criteria

Reject H2-H if:
- exact CSP finds equivalent witnesses cheaply;
- large witness multiplicity appears immediately;
- the pairwise relation admits another structural factorization;
- geometry does not materially change attack complexity relative to H1.

If rejected, do not repair it by merely:
- increasing the surface genus;
- choosing a larger finite simple group;
- enlarging the conjugacy class.

A successor must change the verifier relation, likely by coupling face-level/higher-order constraints.

## 9. Security status

No post-quantum, one-wayness, IND-CPA, IND-CCA, or concrete-security claim exists.
