## 1. Full honest law and a finite exact isotropic-plane count

Let `q` be any prime power, `V=F_q^n`, `2<=d<n`, `c=n-d`, and `m>=1`. Draw a hidden `d`-plane `H` from **any prior**, independently of the forms. Conditional on `H`, independently sample `m` uniform alternating forms `A_i` with `A_i|_{H x H}=0`. Publish the *entire* tuple. The accepted output is **any** `d`-plane `L` with `A_i|_{L x L}=0` for all `i`; recovering the sampled `H` is not additionally required.

Let `Z_k(A)` count public simultaneously isotropic `k`-planes, with `Z_0=1`. Write `[a choose b]_q` for a Gaussian binomial and `b(k)=k(k-1)/2`.

**Theorem 1 (exact first moment, every honest prior).** For `0<=k<=n`,

\[
\boxed{
\mathbb E_{\rm honest} Z_k
=\sum_{j=\max(0,k-c)}^{\min(k,d)}
{d\brack j}_q{c\brack k-j}_q
q^{(d-j)(k-j)}
q^{-m\,[b(k)-b(j)]}.}
\]

The expression is exact at finite `n,q,m`, including characteristic two, and conditional on each fixed `H` has the same value.

**Proof.** For any fixed `k`-plane `T` meeting `H` in dimension `j`, the constraints that a form already annihilating `\Lambda^2 H` also annihilate `\Lambda^2 T` have codimension `b(k)-b(j)`. Indeed `\Lambda^2 T \cap \Lambda^2 H=\Lambda^2(T\cap H)`. Thus each independent form accepts `T` with probability `q^{-[b(k)-b(j)]}`. The number of `k`-planes with this intersection dimension is `[d choose j]_q[c choose k-j]_q q^{(d-j)(k-j)}`, by choosing the intersection, quotient image and graph map. Sum the conditional acceptance probabilities. No independence among different `T` is asserted. QED.

## 2. Public-only isotropic-flag attack

Rather than enumerate all `[n choose t]_q` seed planes and *then* discard non-isotropic seeds, enumerate only valid **flags** using the complete published tuple:

1. Start with the empty isotropic plane `U_0=0`.
2. At each isotropic `k`-plane `U_k`, calculate the public simultaneous orthogonal completion
   \[
   S_A(U_k)=\{v\in V:A_i(u,v)=0\ \forall u\in U_k,\ i=1,\dots,m\}.
   \]
   Because `U_k` is isotropic, `U_k\subseteq S_A(U_k)`.
3. Enumerate all **one-dimensional subspaces** of the quotient `S_A(U_k)/U_k`, with a canonical representative and polynomial delay per output; extend by each representative to a `(k+1)`-plane `U_{k+1}`. Every generated extension is isotropic because the forms are alternating.
4. At depth `t`, calculate `S_A(U_t)`. Output it only if it has dimension exactly `d` **and passes the original full verifier**. Otherwise continue. Repeated terminal planes arising from distinct flags may simply be rechecked; no deduplication is assumed.
5. If all flags are exhausted without a verified witness, report `not found` (not a decision of nonexistence on arbitrary inputs).

No step consults `H`, an `H`-dependent chart, a conditional-membership oracle, or a tensor-restricted oracle. A complete flag `0<U_1<...<U_k=T` can be generated by this procedure **if and only if** its terminal `T` is isotropic; all of its predecessors are then isotropic as well.

Let
\[
F_k(q)=\prod_{i=1}^k{i\brack1}_q,\qquad F_0=1.
\]
This is the exact number of complete subspace flags **inside one** `k`-plane. Consequently the number of visited depth-`k` nodes is **exactly** `F_k(q) Z_k(A)` (counting paths, not distinct terminal planes).

**Theorem 2 (success and source-aware work).** For `1<=t<=d` and `mt>=c`, the above deterministic public algorithm produces a fully accepted witness on the unfiltered honest source with probability at least

\[
\boxed{p_t=\prod_{i=0}^{c-1}(1-q^{i-mt}).}
\]

Its per-instance field-operation work `W(A)` has the **pointwise** bound

\[
\boxed{W(A)\le P(n,m,t,\log q)
  \sum_{k=0}^t F_k(q)Z_k(A),}
\]

for an implementation-dependent fixed polynomial `P`, and therefore the **exact finite-sum expected-work upper bound**

\[
\boxed{\mathbb E_{\rm honest} W
\le P(n,m,t,\log q)\sum_{k=0}^t F_k(q)
\sum_{j=\max(0,k-c)}^{\min(k,d)}
{d\brack j}_q{c\brack k-j}_q
q^{(d-j)(k-j)-m[b(k)-b(j)]}.}
\]

**Proof.** Each valid `t`-plane has all `F_t(q)` complete flags and is therefore reached. For any fixed `H`, choose a `t`-plane `T_*(H)\subseteq H` by a rule depending **only** on `H`, not on the independently drawn forms. Its public completion equals `H` with the [exact fixed-seed probability](F0-planted-ti-public-seed-completion.md) `p_t`; that `T_*(H)` is isotropic and is reached by the traversal. A different terminal plane might produce another accepted witness, which can only increase success. Each flag node generates precisely its projective quotient children with polynomial work per child; each terminal completion and verification is polynomial. Count all nodes and use Theorem 1. QED.

**Optional capped-runtime variant.** Set `B=P\sum_{k<=t}F_k\mathbb E Z_k`, an explicit (possibly huge) source-aware upper bound. Running the same verifier-gated traversal with budget `B/\varepsilon` for `0<\varepsilon<1` gives deterministic capped work and unconditional success at least `p_t-\varepsilon`, by Markov's inequality on the full traversal work. If this bound is negative, replace it by zero. This does **not** imply polynomial work; it only converts an expected-work result to an explicit probabilistic work guarantee.

## 3. Sparse `d<c` regime: a leading-exponent improvement, not a breakthrough

Assume fixed `q`, `d/n\to\alpha\in(0,1/2)`, `m\asymp n/\log n`, `c=n-d`, and select `t=\lceil(c+s)/m\rceil` for `s\to\infty` with `s=o(n)`. Then `t=\Theta(\log n)`, `t<=d` eventually, and the fixed-seed failure bound is at most `q^{-s}/(q-1)`.

For all `k<=t`, the summand `j=0` of Theorem 1 is
\[
{c\brack k}_q q^{dk-mb(k)}.
\]
Using `q^{a(b-a)}\le {b\brack a}_q\le C_q q^{a(b-a)}` for `C_q=\prod_{i>=1}(1-q^{-i})^{-1}<4`, the ratio of any `j>=1` summand to the `j=0` summand is at most
\[
C_q^2\,q^{-j(c-k+j)+m b(j)}.
\]
Since `m(t-1)<=c+s`, `s=o(n)`, and `t=o(n)`, this ratio is `q^{-\Omega(jn)}` uniformly over `1<=j<=k<=t`. Thus
\[
\log_q(\mathbb E Z_k)=k(n-k)-m b(k)+O_q(1)
\]
uniformly (and `\log_q F_k=b(k)+O_q(k)`). The leading exponent of `F_k \mathbb E Z_k` increases with `k<=t`, because its successive difference is `n-(m+1)k-1>0` eventually. Consequently
\[
\boxed{\log_q\mathbb E W
\ \le\ t(n-t)-(m-1)b(t)+O_q(t+\log n)
\ =\ \frac{cn-c^2/2}{m}+o(n^2/m).}
\]
Here `P` is a fixed polynomial and the last equality is a **leading asymptotic upper bound**, not an exact running-time identity. The previous all-plane enumeration has leading exponent `cn/m+o(n^2/m)`; constructing only isotropic flags saves `c^2/(2m)+o(n^2/m)` **in this expected-work upper bound**. Both bounds remain `q^{\Theta(n\log n)}` for these choices, with no polynomial public seed extraction.

For `\alpha=1/3`, the displayed leading exponents are `(4/9)n^2/m` for the flagged upper bound versus `(2/3)n^2/m` for the all-plane bound. These are asymptotic **analytical work exponents**, not measured attacks or security bits.
