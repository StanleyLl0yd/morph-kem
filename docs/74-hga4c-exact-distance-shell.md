# 74 — HGA4c exact-distance Hurwitz endpoint shell calibration

## Status

**HGA4c is a bounded falsification/calibration experiment in progress.** HGA4b showed that exact path self-avoidance is not enough: substantial equivalent shortening remains routine and the greedy generator can dead-end. HGA4c removes planted-history non-geodesicity by selecting targets from exact public action-distance shells.

HGA4c is not a scalable secret generator, trapdoor primitive, KEM, one-way function, post-quantum assumption, or production-security construction.

## Construction

Reuse the HGA4 action of `B3` on triples of reduced words in `F(a,b)`. Declared toy distances are `D=4,6,8`.

For each deterministic source:

1. build the complete action-state BFS ball through depth `D`;
2. retain the exact shell `S_D` of states first discovered at depth `D`;
3. choose the target that maximizes total reduced component length, breaking ties by a seeded public hash;
4. retain one shortest certificate and capped shortest-path multiplicity as generator evidence;
5. publish only source, target and public distance bound `D`.

The target is therefore certified to have exact action distance `D`. The generator does not use the later bidirectional attack output, but constructing the exact shell is itself expensive and is only a calibration technique.

## HGA-A007

Run the existing independent public bidirectional HGA4 recovery from source and target:

- build forward/backward balls to the split public bound;
- find any meet state;
- construct an equivalent connector;
- verify the endpoint exactly.

Because the target comes from an exact shell, a recovered connector shorter than `D` would indicate a generator/measurement bug and is treated as an error rather than an attack result.

Record the attacker's state work relative to the full generator ball. Also preserve exact shortest-path multiplicity from the generator BFS as a calibration statistic; equality with the retained generator certificate is reference-only.

## Measurements

Record:

- exact distance;
- generator ball and outer-shell sizes;
- generator transitions;
- selected target total reduced length;
- capped shortest-path multiplicity;
- attacker forward/backward states and transitions;
- meet-state count;
- recovered connector length and endpoint acceptance;
- post-success equality with the retained certificate;
- attacker state count as a fraction of generator-ball states;
- deterministic multi-seed curves.

## Gate

Do not reject HGA4c merely because exact search solves a toy endpoint whose exact shell was itself generated by exact search. The useful question is whether bidirectional recovery, finite quotients, stabilizers or equivalent-path multiplicity make the selected endpoints substantially easier than the full exact shell construction suggests.

If independent recovery routinely visits only a small fraction of the generator ball, record that as failure of this bounded endpoint-distribution calibration—not as a theorem that the infinite Hurwitz action is easy.

If the gate survives, the next work must still include finite representation quotients, stabilizer/canonical-form probes and larger bounded shell growth before any architectural advancement.

No security claim.
